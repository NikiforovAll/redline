Hover a line in the diff and add a comment, or reply under one of Claude's notes.

- **Send to Agent** on a thread wakes the Claude Code session with that thread right away.
- **Redline: Submit review** sends every open comment in the round at once.
- `Ctrl+Alt+]` and `Ctrl+Alt+[` move between notes.

Claude answers inside the thread, and the round stays open for another pass.

A Claude Code session in a terminal wakes on its own. In the Claude Code VS Code extension, type `/redline:redline-connect listen` so the session polls for your comments instead.
