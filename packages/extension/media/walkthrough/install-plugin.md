Redline has two halves. This extension renders the review. The Claude Code plugin gives Claude the skills and the MCP server that open a round here and pick up your comments.

The button runs these in a terminal:

```
claude plugin marketplace add nikiforovall/redline
claude plugin install redline@redline
```

Or type the same two commands as `/plugin marketplace add nikiforovall/redline` and `/plugin install redline@redline` inside a Claude Code session.

This step completes on its own once the plugin shows up in `~/.claude/plugins/installed_plugins.json`. Start a new Claude Code session afterwards so it loads the skills.
