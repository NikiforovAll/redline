In a Claude Code session opened on this folder, ask for a tour of a change:

```
/redline:redline-tour
```

Claude opens a multi-file diff in this window with its notes attached as comment threads. Rounds also appear in the **Redline** view in the secondary sidebar.

To start a round yourself, run **Redline: Compare…** and pick two refs, then `/redline:redline-connect` in Claude Code so it picks up your comments.
